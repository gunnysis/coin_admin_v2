# 지난달 유동비 데이터 확인 방법

## 개요
유동비 기능에서 이전 달의 데이터를 확인하는 방법을 안내합니다.

## 방법 1: 월 선택기 화살표 버튼 사용 (가장 간단)

### 단계별 가이드

1. **유동비 탭으로 이동**
   - 하단 탭 네비게이션에서 "유동비" 탭 선택

2. **월 선택기 찾기**
   - 화면 상단의 유동비 총액 카드에서 월 선택기를 확인
   - 현재 선택된 월이 표시됨 (예: "2024년 1월")

3. **이전 달로 이동**
   - 월 선택기의 **왼쪽 화살표 버튼 (←)** 클릭
   - 한 번 클릭하면 바로 이전 달로 이동
   - 예: 현재가 2024년 1월이면 → 2023년 12월로 이동

4. **데이터 확인**
   - 월이 변경되면 자동으로 해당 월의 유동비 데이터가 로드됨
   - 총액, 항목 목록, 차트 등이 모두 해당 월 데이터로 업데이트됨

### 시각적 가이드

```
┌─────────────────────────────────────┐
│  [←]  2024년 1월  [선택]  [→]      │  ← 월 선택기
│  ────────────────────────────────   │
│  유동비 총액                         │
│  500,000원                          │
│  총 15개 항목                        │
└─────────────────────────────────────┘
```

**← 버튼 클릭 시:**
```
┌─────────────────────────────────────┐
│  [←]  2023년 12월  [선택]  [→]      │  ← 이전 달로 변경됨
│  ────────────────────────────────   │
│  유동비 총액                         │
│  450,000원                          │  ← 지난달 데이터 표시
│  총 12개 항목                        │
└─────────────────────────────────────┘
```

## 방법 2: 여러 달 이전 데이터 확인

여러 달 이전의 데이터를 확인하려면:

1. **연속으로 화살표 버튼 클릭**
   - 왼쪽 화살표 버튼을 여러 번 클릭
   - 예: 3개월 전 데이터를 보려면 3번 클릭

2. **현재 달로 돌아가기**
   - 오른쪽 화살표 버튼 (→)을 클릭하여 다음 달로 이동
   - 또는 월 표시 영역에 "현재" 배지가 표시될 때까지 오른쪽 화살표 클릭

## 방법 3: 현재 달로 빠르게 돌아가기 (향후 구현 예정)

현재는 화살표 버튼으로 이동해야 하지만, 향후 다음 기능이 추가될 예정입니다:

- **월 표시 영역 탭**: 월 선택 모달 열기
- **"현재 달" 빠른 선택 버튼**: 한 번에 현재 달로 이동

## 주의사항

### 버튼 비활성화 상태
- 현재 달보다 이전 달이 없으면 왼쪽 화살표 버튼이 비활성화됩니다 (투명하게 표시)
- 예: 현재가 2024년 1월이고, 선택된 월도 2024년 1월이면 왼쪽 화살표는 비활성화

### 데이터 자동 로딩
- 월을 변경하면 자동으로 해당 월의 데이터를 조회합니다
- 네트워크가 느린 경우 로딩 시간이 걸릴 수 있습니다

### 현재 월 표시
- 선택된 월이 현재 월과 같으면 "현재" 배지가 표시됩니다
- 예: `2024년 1월 [현재]`

## 실제 사용 예시

### 시나리오: 지난달 지출 확인

1. 앱 실행 → 유동비 탭 선택
2. 월 선택기에서 왼쪽 화살표 (←) 클릭
3. 화면이 지난달 데이터로 업데이트됨
4. 총액, 항목 목록, 차트 등 지난달 정보 확인
5. 필요시 오른쪽 화살표 (→)로 현재 달로 복귀

### 시나리오: 3개월 전 데이터 확인

1. 유동비 탭 선택
2. 왼쪽 화살표 버튼을 3번 연속 클릭
3. 3개월 전 데이터 확인
4. 오른쪽 화살표 버튼을 3번 클릭하여 현재 달로 복귀

## 기술적 세부사항

### 자동 데이터 조회
- 월이 변경되면 `useVariableExpensesPaginated`와 `useVariableExpensesTotal` 훅이 자동으로 해당 월의 데이터를 조회합니다
- React Query 캐싱으로 이미 조회한 월의 데이터는 빠르게 표시됩니다

### 상태 관리
- 선택된 월은 `AppContext`의 `selectedVariableMonth`에 저장됩니다
- 앱을 종료하고 다시 열어도 기본값은 현재 월로 설정됩니다

## 향후 개선 사항

다음 기능들이 추가될 예정입니다:

1. **월 선택 모달**
   - 월 표시 영역을 탭하면 하단 시트 모달이 열림
   - 최근 12개월 목록에서 직접 선택 가능

2. **스와이프 제스처**
   - 좌우 스와이프로 월 변경
   - 더 직관적인 사용자 경험

3. **월별 비교 카드**
   - 현재 월과 이전 월을 한 화면에서 비교
   - 증감액, 증감률 표시

## 문제 해결

### Q: 왼쪽 화살표가 작동하지 않아요
**A:** 현재 달보다 이전 달이 없으면 버튼이 비활성화됩니다. 현재 달이 가장 오래된 데이터인 경우입니다.

### Q: 데이터가 로드되지 않아요
**A:** 
- 네트워크 연결 확인
- 앱을 새로고침 (Pull-to-refresh)
- 해당 월에 데이터가 실제로 있는지 확인

### Q: 현재 달로 돌아가고 싶어요
**A:** 오른쪽 화살표 버튼을 클릭하여 다음 달로 이동하세요. 현재 달에 도달하면 "현재" 배지가 표시됩니다.
