## 지난달 유동비 데이터 확인

### 방법: 월 선택기 화살표 버튼 또는 스와이프

1. **유동비 탭** → 하단 탭에서 "유동비" 선택
2. **월 선택기** → 유동비 총액 카드 상단, 현재 월 표시 (예: "2024년 1월")
3. **이전 달** → **왼쪽 화살표 (‹)** 클릭 → 해당 월 데이터 자동 로드
4. **현재 달로** → 오른쪽 화살표 (›) 클릭 또는 "현재" 배지가 나올 때까지

월 선택기를 **좌우로 스와이프**해도 이전/다음 달로 이동합니다. 여러 달 이전은 왼쪽 화살표를 연속 클릭(또는 연속 스와이프). 데이터는 React Query로 캐싱되며, 선택 월은 `AppContext.selectedVariableMonth`에 저장됩니다.

### FAQ

- **Q: 왼쪽 화살표가 안 눌려요**
  A: 화살표는 항상 활성화되어 있습니다(과거·미래 달 이동 제한 없음). 반응이 없으면 좌우 스와이프로 이동하거나 앱을 재시작해 보세요.
- **Q: 데이터가 안 나와요**
  A: 네트워크·Pull-to-refresh·해당 월 데이터 존재 여부 확인.
- **Q: 현재 달로 돌아가고 싶어요**
  A: 오른쪽 화살표 (›)를 눌러 "현재" 배지가 나올 때까지 이동하세요.
